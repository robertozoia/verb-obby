# Verb Obby

Minijuego 3D estilo Roblox (three.js) para practicar verbos en inglés de 6.º de primaria:

- Los verbos del diálogo *First day at TTS* (Student's Book, p. 15).
- Los 89 verbos irregulares de la tabla del libro (p. 206–207).

Tiene tres etapas: caza de verbos, puente de cristal del pasado y puertas regular/irregular.

**Jugar:** https://robertozoia.github.io/verb-obby/

`verb-obby.html` es la versión fuente (fragmento para Claude Artifacts); `index.html` es la misma página como documento HTML completo para GitHub Pages.
